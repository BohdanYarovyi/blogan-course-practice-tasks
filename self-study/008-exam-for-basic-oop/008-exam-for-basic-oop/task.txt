==============================================================
  ЗАВДАННЯ: ІНВЕНТАР ДЛЯ ГРИ
==============================================================

Без наслідування, лише класи, композиція і friend / const / static.


--------------------------------------------------------------
  КЛАСИ
--------------------------------------------------------------

1. Item - предмет
   - поля: id (унікальний, через static лічильник), name,
     weight, value, quantity
   - методи: print() const, гетери, add_quantity(int),
     remove_quantity(int)

2. Inventory - сховище
   - контейнер: масив або std::vector<Item>
   - обмеження: ліміт ваги та кількість слотів
   - методи:
       add_item(const Item&)
           якщо такий предмет уже є - збільшує кількість;
           відмовляє, якщо перевищено ліміт ваги
       remove_item(int id, int quantity)
       find_item(int id) const
       total_weight() const
       print() const

3. Player - гравець
   - поля: ім'я, золото, Inventory
   - методи:
       buy_item(Item&, ...)
       sell_item(int id, int quantity)
           змінюють золото й інвентар
       print() const


--------------------------------------------------------------
  ВИМОГИ
--------------------------------------------------------------

  1. Кожен клас у своїх .hpp / .cpp, include guards.
  2. Жодних public полів.
  3. const-коректність: const-методи, const& в параметрах.
  4. Інваріанти: кількість і золото не йдуть у мінус,
     вага не перевищує ліміт. Методи повертають bool
     (вдалося чи ні).
  5. Хоча б одне friend (наприклад, Player -> доступ до
     внутрішніх деталей Inventory) і хоча б один
     forward declaration.
  6. Імена функцій у snake_case.


--------------------------------------------------------------
  ТЕСТ У main
--------------------------------------------------------------

  - створити гравця
  - додати кілька предметів
  - спробувати додати зайвий (має відмовити)
  - продати частину
  - вивести стан
